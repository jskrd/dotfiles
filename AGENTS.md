# Agent prompts

`home/.claude/` holds prompts loaded into agent context: `CLAUDE.md`, `agents/*.md`, `skills/*/SKILL.md`. Every word there costs tokens on every load.

When editing them:

- Use the fewest words that still get the point across.
- Before adding a line, be certain it is needed and cannot be shorter.
- Cut, then reread. If the meaning survives, keep the cut.
